# Game Graphical Mods

Open-source graphical modifications maintained by decoded-brain.

| Game | Features | Status |
| --- | --- | --- |
| [Dishonored 2](mods/dishonored-2/) | RenoDX HDR conversion | Beta |
| [Detroit: Become Human](mods/detroit-become-human/) | HDR, Vulkan DLAA, ultrawide and UI compensation | Experimental |
| [Frostpunk 2](mods/frostpunk-2/) | RenoDX UE Extended HDR support | Experimental |

Compiled packages are available under [Releases](https://github.com/decoded-brain/game-graphical-mods/releases). ReShade and NVIDIA DLSS binaries are deliberately not redistributed here.
