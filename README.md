# Game Graphical Mods

Open-source graphical modifications maintained by decoded-brain.

| Game | Features | Status |
| --- | --- | --- |
| [Dishonored 2](mods/dishonored-2/) | RenoDX HDR, Luma Neutwo and PsychoV-17/22 tone mapping | Beta |
| [Detroit: Become Human](mods/detroit-become-human/) | Split HDR Core and Effects addons, Vulkan DLAA, native DOF v2, ultrawide and UI compensation | Experimental |
| [Frostpunk 2](mods/frostpunk-2/) | RenoDX UE Extended HDR support | Experimental |

Compiled packages are available under [Releases](https://github.com/decoded-brain/game-graphical-mods/releases/latest). Each archive contains only the custom addon binaries and the notices needed for that mod. ReShade, NVIDIA DLSS/NGX runtimes, game files, personal presets and development tools are deliberately not redistributed here.

The source directories are provenance snapshots of the game-specific code used by the published binaries. They are intended to be placed into the corresponding RenoDX source tree rather than built as standalone projects.
