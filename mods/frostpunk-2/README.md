# Frostpunk 2

Experimental Frostpunk 2 HDR support for RenoDX UE Extended.

## Installation

1. Install the current ReShade Full Add-On build for the game's DirectX 12 executable.
2. Copy `renodx-ue-extended.addon64` from the release archive into `Frostpunk2/Frostpunk2/Binaries/Win64`.

The addon is the complete UE Extended binary, not a standalone two-file patch. Only the Frostpunk-specific source delta is mirrored in this repository; build it in the corresponding RenoDX tree.
